# WRF PALMAS V0.6 — mapas localizáveis e GIFs

A V0.6 transforma a primeira previsão regional alimentada pelo GFS em **mapas com contexto geográfico**. Continua sendo um **experimento** com geografia WPS de baixa resolução e parametrização convectiva; **não é um alerta nem uma previsão operacional de tornados**.

## Novidades

- **Latitude/longitude + fronteiras de países, estados/províncias e litoral** usando Natural Earth 50m via Cartopy. As linhas vêm de dados vetoriais geográficos e não da imagem de temperatura.
- **Cidades de referência**, marcadas apenas quando estão realmente dentro da extensão do domínio.
- **Temperatura 2 m + vento 10 m**, com cores e vetores de vento.
- **Chuva acumulada** desde o início da simulação, obtida por `RAINC + RAINNC` (se ambas as variáveis de acumulação estiverem disponíveis; se apenas uma estiver disponível, o script usa a disponível e o resultado deve ser interpretado com cautela).
- **Refletividade WRF**: produto separado, apenas quando `REFL_10CM` está no `wrfout`. O script usa máximo vertical quando o campo é 3D. **Se não houver a variável, declara indisponível, em vez de fabricar um radar a partir de temperatura ou chuva acumulada.**
- **GIF por campo**, montado a partir de todos os frames salvos.
- **Intervalo de saída: 30 min**. Em uma previsão de 3 h, a meta é 7 quadros.
- **Artefato separado com NetCDF brutos:** `WRF-PALMAS-V06-WRFOUT-RAW`, salvo **antes** da plotagem, para não perder a simulação se Cartopy ou os mapas falharem.

## Arquivos e comandos

Workflow completo: [real-gfs-v05.yml](../.github/workflows/real-gfs-v05.yml) (agora denominado V0.6 no GitHub).

Para plotar localmente se você já possui os `wrfout_d01_*`:

```sh
python3 -m pip install numpy netCDF4 matplotlib pillow cartopy
python3 scripts/plot_real_v06.py --run-dir /pasta/com/wrfout --out-dir results/v06
```

Saída:

- `results/v06/t2/t2_*.png` e `results/v06/gifs/t2_anim.gif`;
- `results/v06/rain/rain_*.png` e `results/v06/gifs/rain_anim.gif` (se há campos de chuva);
- `results/v06/refl/refl_*.png` e `results/v06/gifs/refl_anim.gif` (se `REFL_10CM` existir);
- `results/v06/summary.json`, com status de disponibilidade e horários.

**Replotar sem WRF:** no [workflow de replot](../.github/workflows/real-gfs-v06-replot.yml), informe o ID de uma execução V0.6 que tenha guardado `WRF-PALMAS-V06-WRFOUT-RAW`. O replot somente baixa o artifact e gera mapas/GIFs; não recompila, não baixa GFS e não executa `wrf.exe`. Artifacts expiram conforme a retenção.

## Cuidados técnicos

- Natural Earth pode precisar ser baixado pelo Cartopy na primeira renderização; se o serviço externo estiver indisponível, esta etapa pode falhar, **mas o artifact de NetCDF bruto já deve estar salvo**.
- Cidades são marcadores de contexto; não são grade de previsão.
- Os mapas usam a extensão real da grade `XLAT/XLONG`, não um retângulo arbitrário.
- O WRF de 9 km não resolve detalhadamente tornados ou estruturas convectivas individuais. Refletividade modelada também não é radar observado.
- A V0.5 que gerou só PNGs não preservou o `wrfout`; por isso ela **não** permite replotar refletividade e chuva. O primeiro V0.6 completo ainda precisa rodar uma vez para produzir esses dados.

Veja os **testes da V0.6** em GitHub Actions antes de tratar os mapas como publicados e validados.
